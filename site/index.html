01 / THE OPPORTUNITY

Recognition should travel.

One artist.
Too many disconnected records.

Streaming platforms, ticketing systems, and catalogs each see a part of the picture. O2A proposes a shared way to connect those records through claims the participant can sign and others can verify.

Room for different applications.

Identity + evidence

SPECIFICATION IN PROGRESS
02 / DISCOVERY

Portable profiles

Rebuildable catalogs, with Pubky / PKARR as an optional public-profile and discovery adapter to evaluate.

PROPOSED INTEGRATION
03 / ECONOMIC USE

Payments + digital rights

Lightning for sat payments; RGB / Bitcoin for selected rights and state transitions. USDt swaps require a separately tested route.

OPTIONAL APPLICATION WORK

A signature proves authorship. A Bitcoin commitment supports integrity. Neither automatically establishes a real-world identity or ownership of creative rights.

05 / START SMALL. PROVE THE MODEL.

Currently in design

From a shared idea
to a working protocol.

The first milestone is one artist, one venue, a shared event, and independent clients reaching the same result from the same evidence.

  1. 01
    NOW

    Specify the foundation

    Define schemas, canonical encoding, authorization, and fixed verification vectors.

  2. 02
    NEXT

    Independent verifiers, conflicting claims, key changes, and a portable event package.

  3. 03
    THEN
