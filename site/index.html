01 / THE OPPORTUNITY

Recognition should travel.

One participant.
Too many rented identifiers.

Streaming platforms, ticketing systems, and catalogs each assign their own IDs. O2A proposes a public-key-rooted ID the owner controls locally and can connect to those records with portable evidence.

05 / BUILT IN LAYERS

Each technology has a specific job.

A Bitcoin foundation.
Evidence at the edges.

01 / IDENTITY

Bitcoin + RGB

A dedicated BIP340 root and RGB client-side state cover genesis, controller rotation, recovery rules, and revocation.

REQUIRED FOUNDATION
02 / EVIDENCE

Names + discovery

DNS, social posts, peer attestations, Pubky bindings, and optional Nostr posts make claims discoverable and independently checkable.

POLICY-EVALUATED
03 / WALLET

Self custody

The owner stores seeds, keys, RGB consignments, attestations, and proof packages locally, using a full node or clearly labeled light mode.

CLIENT-SIDE BY DESIGN

Bitcoin establishes order, anchors, and seals. RGB validates supplied identity state. Neither declares who is the real artist; wallets reach that conclusion from evidence and a named policy.

06 / START SMALL. PROVE THE MODEL.

Currently in design

From a shared idea
to a working protocol.

The first milestone is a self-custodial wallet creating and recovering identities for an artist, venue, promoter, event, and album, then independent wallets reaching the same result from the same evidence.

  1. 01
    NOW

    Specify the foundation

    Freeze BIP340 roots, RGB lifecycle schemas, canonical encoding, and verification policies.

  2. 02
    NEXT

    Prove it on regtest

    Genesis, rotation, recovery, revocation, competing names, and portable consignments.

  3. 03
    THEN

    Build the minimum wallet

    Local custody, full-node and explicit light modes, proof exchange, DNS/social checks, Pubky, and optional Nostr.

  4. 04
    LATER

    Test and release identity

    Public testnet precedes mainnet. Payments, GatePass, SplitNight, and additional rights profiles have separate gates.
